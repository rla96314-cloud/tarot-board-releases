# 타로 보드 릴리스

[타로 보드](https://github.com/rla96314-cloud/tarot-board) Windows 설치 파일을 배포하는 저장소입니다. 소스는 비공개이고 여기에는 빌드 결과만 올라옵니다.

- `TarotBoard-Setup-x.y.z.exe` 설치형 (자동 업데이트 지원)
- `TarotBoard-Portable-x.y.z.exe` 포터블 (자동 업데이트 없음)

최신 버전: https://github.com/rla96314-cloud/tarot-board-releases/releases/latest
